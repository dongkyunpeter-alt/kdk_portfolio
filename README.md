# 강동균 포트폴리오

풀무원 메인페이지와 바른먹거리 하위 5개 페이지의 설계·구현 과정을 정리한 독립 포트폴리오입니다.

## 실행

인터넷 연결 상태에서 `index.html`을 브라우저로 열면 됩니다. Tailwind CSS 브라우저 런타임을 CDN으로 불러오므로 인터넷 연결이 필요합니다.

로컬 서버로 확인하려면 이 폴더에서 다음 명령을 실행합니다.

```powershell
python -m http.server 4173
```

그다음 `http://localhost:4173`으로 접속합니다.

## 배포

이 폴더 전체를 별도 Git 저장소에 올리면 GitHub Pages로 배포할 수 있습니다.
